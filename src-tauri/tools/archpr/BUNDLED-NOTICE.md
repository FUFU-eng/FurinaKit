# ARCHPR 随附组件说明

- 无需另外安装 ARCHPR；首次启动在缺少可用共享组件时，仅设置当前用户的 `Software\ElcomSoft\Common Files\Location`，指向本目录。
- 不写入机器级注册表，不要求管理员权限，不覆盖已安装且完整的 ElcomSoft 共享组件路径。

- 来源为维护者电脑已有的 ElcomSoft 安装组件，文件校验信息见 runtime-manifest.json；不从第三方 DLL 下载站取件。
- 这些文件的再分发许可尚需发布者确认，本次构建用于本地修复验收，不表示已经具备公开再分发权。
