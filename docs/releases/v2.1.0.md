# FurinaKit v2.1.0 · Tauri 原生版

## 下载

- **安装版（推荐）**：`FurinaKit.Setup.2.1.0.exe`，约 115.5 MiB。
- **便携版**：`FurinaKit-v2.1.0-windows-x64.zip`，完整解压后运行 `FurinaKit.exe`。
- `FurinaKit.BuildResources.2.1.0.zip` 供源码构建使用；普通用户不需要单独下载。
- 单独的 `ffmpeg.exe` / `ffprobe.exe` 为组件修复备用，安装包本身已经内置二者。

- 设置中所需的 16 个下载文件已经过完整大小和 SHA-256 校验，清单见 `MODEL-DOWNLOADS.json`。
